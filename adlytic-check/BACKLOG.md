## نواقص معروفة في P0
- **النشر الحي لم يتم** من جلسة البناء (شبكة محجوبة عن `api.cloudflare.com` وبلا API token) — `docs/DEPLOYMENT.md`.
- **التحليل الحقيقي لم يُجرَّب**: لا مفتاح مزوّد في بيئة البناء. كل اختبارات التحليل تستخدم مزوّداً وهمياً؛ جودة الملاحظات الفعلية، والتصريح بعدم قراءة نص الصورة، ومقاومة الحقن **عند النموذج نفسه** تحتاج تجربة حقيقية.
- **Turnstile الإنتاجي** يحتاج إنشاء widget وتجربة بشرية واحدة.
- **سياسة احتفاظ Anthropic بالبيانات**: صفحة الخصوصية تصفها بعبارة عامة؛ يجب أن يتحقق صاحب المشروع من المدة الحالية في شروط Anthropic ويحدّث النص بدقة.
- **حد CPU في خطة Workers المجانية** (10ms): تحويل الصورة base64 وhash يتمان بدوال native وعادةً سريعان، والصورة مصغّرة في المتصفح، لكن لم يُقس الزمن على حساب مجاني حقيقي. إن ظهرت أخطاء CPU فالحل خطة Workers Paid.
- **حذف الكوكي** يعيد الحصة لذلك المتصفح؛ التعويض: Turnstile + سقف يومي للخدمة + حد إنشاء جلسات لكل شبكة. الحل الجذري حسابات (المرحلة B).
- **CI**: لم يُضف workflow لأن المشروع داخل مستودع Adlytic (مسار `.github/` في جذره يخص Adlytic). عند نقله لمستودع مستقل: `npm ci && npm run typecheck && npm test` بلا أسرار إنتاج.
- **حد معدل الأحداث** (60/ساعة/زائر) والتنظيف المجدول (cron يومي) مُنفَّذان؛ cron لم يُختبر حياً.
- **الترجمة الإنجليزية**: البنية جاهزة (`src/i18n/ar.ts`)، والمحتوى غير موجود.
