# Evaluation

Benchmark: `eval/fixtures/cases.json` — **46 synthetic cases** (39 images rendered from a spec, 7
text-only), fixture version `fx-2026-10-19.1`. Every image is generated by
`eval/fixtures/generate.ts`, so the exact image text, prices and CTA presence are known.
Split: 28 dev / 18 held-out (ids where n mod 5 ∈ {0,3}). No real customer content.

Coverage tags: clean (5), no CTA (5), unclear product (2), image/text price conflict (3), small
text (3), crowded (3), image without text (3), text only (8), Eastern/mixed numerals and Arabic
separators (5), Arabic/English mix (4), temptation to invent offers (3), prompt injection in image
and in text (2), Iraqi dialect (3), low contrast (2), vertical 9:16 safe-zone violation/ok (2),
phone number in image (1), medical claim (1).

Scoring (`eval/score.ts`) is **truth-based**: invented facts are checked against the fixture's
real owner text + image text, not against the facts the model says it read.

Runner: `eval/run.ts` in GitHub Actions (`adlytic-check-eval.yml`), hard call cap per run,
synthetic content only in public logs.

## Retrieval (offline, `npx tsx eval/retrieval.ts`, labels = `relevantRules` on 46 fixtures)

| Strategy | Rules sent | Recall (all) | P@5 | nDCG@5 | P@8 | nDCG@8 |
|---|---|---|---|---|---|---|
| Baseline: all 18 rules, KB order | 18 | 1.00 | 0.235 | 0.410 | 0.274 | 0.555 |
| Applicability filter | 13.4 | **1.00** | 0.287 | 0.464 | **0.329** | **0.637** |
| Filter + BM25 order (engine) | 13.4 | **1.00** | **0.326** | **0.475** | 0.299 | 0.588 |

The filter never drops a labelled rule and cuts the prompt by 25 %. BM25 ordering helps slightly
at 5 and hurts at 8, so all filtered rules are sent (order matters little). Embeddings are not
justified at this KB size (decision D-005).
