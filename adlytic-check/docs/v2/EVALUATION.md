# Evaluation

Benchmark: `eval/fixtures/cases.json` — **46 synthetic cases** (39 images rendered from a spec, 7
text-only), fixture version `fx-2026-10-19.1`. Every image is generated by
`eval/fixtures/generate.ts`, so the exact image text, prices and CTA presence are known.
Split: 28 dev / 18 held-out (ids where n mod 5 ∈ {0,3}). No real customer content.

Coverage tags: clean (5), no CTA (5), unclear product (2), image/text price conflict (3), small
text (3), crowded (3), image without text (3), text only (8), Eastern/mixed numerals and Arabic
separators (5), Arabic/English mix (4), temptation to invent offers (3), prompt injection in image
and in text (2), Iraqi dialect (3), low contrast (2), vertical 9:16 safe-zone violation/ok (2),
phone number in image (1), medical claim (1).

Scoring (`eval/score.ts`) is **truth-based**: invented facts are checked against the fixture's
real owner text + image text, not against the facts the model says it read.

Runner: `eval/run.ts` in GitHub Actions (`adlytic-check-eval.yml`), hard call cap per run,
synthetic content only in public logs.

## Baseline — V1 as deployed (2026-10-19, run 39299983377)

`claude-haiku-4-5`, 45 s budget, 3 000 output tokens — exactly the live configuration.

| Metric | Value |
|---|---|
| Completed / attempted (first runs) | **32 / 46 (69.6 %)** |
| Failures | 12 × `provider_timeout`, 2 × `invalid_provider_output` |
| Repair rate | 37 % (14 schema, 3 unsupported facts) |
| Root cause | outputs average ~2 700 tokens; many hit the 3 000 cap → truncated JSON → repair → budget exhausted |
| Latency p50 / p90 / max | 26.4 s / 30.3 s / 45.0 s |
| Cost (77 calls) | $1.06 → ~$0.014 per call |
| Invented commercial facts in published copy (truth-based) | **0** (3 reports needed the strip fallback) |
| Price read correctly from image | 5 / 14 (36 %) — Eastern-Arabic zeros «٠» read as dots or dropped |
| Image/text price conflict noticed | 2 / 3 |
| CTA verdict matches expectation | 17 / 19 |
| Offer-clarity verdict matches | 15 / 23 — V1 mixes "missing CTA" into message clarity |
| Small/low-contrast text flagged | **0 / 5** — V1's visual axis judges photo style, not text size |
| Legibility class | 31 / 32 |
| Prompt injection resisted | 2 / 2 |
| Phone number surfaced as a fact | 0 |
| Run-to-run agreement on 4 verdicts (7 pairs) | 0.75 |

Scorer corrections found while reading the baseline (applied before any V2 comparison):
the Arabic comma «،» and «٫» are thousands separators; a negated disclaimer
(«لا نستطيع التنبؤ… نسبة النجاح») is not prediction language.
