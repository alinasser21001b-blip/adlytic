# دوائي

نموذج تفاعلي مستقل لمنصة عراقية تساعد المريض في العثور على دوائه لدى صيدليات
قريبة وموثقة. جوهر المنتج هو طلب محدود الزمن تتلقى الصيدليات المطابقة إشعارًا
به، ثم ترسل عروضًا منظمة تشمل التوفر والسعر والجاهزية والاستلام.

## ما يتضمنه النموذج

- مسار بحث مباشر دون إنشاء طلب.
- إنشاء طلب بالكتابة أو التصوير أو رفع صورة.
- محاكاة مطابقة تدريجية ضمن نطاق جغرافي.
- مقارنة عروض مؤكدة ومؤرخة وحجز مؤقت.
- دليل صيدليات بقائمتي الخريطة والقائمة.
- صندوق طلبات للصيدلية ونموذج عرض منظم.
- واجهة عربية RTL متجاوبة مع الهاتف وسطح المكتب.

كل البيانات تجريبية. لا يشغّل النموذج OCR أو مخزونًا فعليًا، ولا يصف دواءً أو
يقرر بديلًا علاجيًا.
