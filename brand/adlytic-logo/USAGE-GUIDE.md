# Adlytic — دليل استخدام الشعار (صفحة واحدة)

**الاتجاه المعتمد:** The Aperture / فتحة الرؤيا  
**القرار الاستراتيجي:** استقلالية كاملة عن AdsPulse (خيار ب)

---

## الألوان

| الدور | Hex | استخدام |
|---|---|---|
| Brand ground / Ink | `#0E4034` | لوح الشعار، نص داكن بديل |
| Signal (نادر) | `#C8F26B` | الشقّ فقط — مرة واحدة لكل سطح |
| Text | `#0B1F19` | كلمة Adlytic في الـ lockup |
| Daylight bg | `#F2F7F4` | خلفيات المنتج الفاتحة |
| Mono black | `#0B1F19` | طباعة / فاتورة |
| Mono white | `#FFFFFF` | على خلفيات داكنة |

**قاعدة الإشارة:** `--signal` يظهر على أرضية العلامة فقط، وبأقصى مرة واحدة في الشاشة. ندرته هي قيمته.

---

## أصغر حجم مسموح

| الأصل | حد أدنى |
|---|---|
| Mark مع لوح | **16×16 px** (favicon) |
| Lockup أفقي | ارتفاع mark **24 px** (عرض إجمالي ≈ 72 px) |
| Monogram احتياطي | **16×16 px** |
| طباعة mark | **8 mm** ارتفاع |

تحت 16px للـ mark الكامل: استخدم `favicon.svg` المبسّط أو `monogram.svg`.

---

## Clear space

اترك مساحة فارغة حول الـ mark تعادل **عرض الشقّ عند منتصفه** (حوالي ⅛ من عرض اللوح) من كل جهة.

```
        ┌─ clear ─┐
    ┌───┤         ├───┐
    │   │  MARK   │   │
    └───┤         ├───┘
        └─────────┘
```

لا تضع نصًا أو أيقونات أو حدود بطاقات داخل هذه المنطقة.

---

## الـ Lockup وRTL

- الـ lockup الأفقي: Mark ثم `Adlytic` بالإنكليزي (LTR داخليًا).
- في واجهة عربية RTL: أبقِ وحدة الـ lockup كما هي (mark + Latin wordmark) وضعها ككتلة واحدة؛ لا تعكس ترتيب الحروف داخل الكلمة.
- بجانب نص عربي: افصل بمسافة clear space كاملة. لا تدمج كلمة عربية داخل رسم الشعار.

---

## سوء الاستخدام — ممنوع

1. تدوير الشقّ ليصير سهمًا أو يصبح أفقيًا «كشريط تقدم.»
2. إضافة رسم بياني / صاروخ / عدسة / نيورونات حول أو داخل اللوح.
3. تغيير `#C8F26B` إلى ذهب أو أزرق Meta أو Pulse Red.
4. وضع الشعار على صورة مزدحمة بدون لوحة لونية صلبة خلفه.
5. تمديد اللوح أو سحق النسب.
6. إضافة ظل متعدد الطبقات أو توهج خارج نظام Daylight.
7. ربط بصري مع شعار AdsPulse (ECG / Pulse Red) في نفس القفل.
