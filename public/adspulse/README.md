# ADS PULSE — Flagship Creative Experience

A self-contained, zero-dependency interactive site. The page itself is the
portfolio: every control on it demonstrates a design capability instead of
describing one.

## Run it

It's a static folder — open `index.html` directly, or serve the folder:

```bash
cd public/adspulse
python3 -m http.server 8080     # → http://localhost:8080
```

(Serving over HTTP is preferred: `file://` blocks the `woff2` font preloads
in Chromium, though the page still works and falls back to system fonts.)

## What's inside

| File | Purpose |
| --- | --- |
| `index.html` | The entire site — markup, design-token CSS, and vanilla-JS runtime (~324 KB, no build step, no external requests) |
| `assets/shot-0*.webp` | The three photographic plates (760px, re-encoded from the original JPEGs — 1.0 MB → 195 KB) |
| `assets/grain.webp` | The film-grain tile used by the duotone treatment |
| `assets/fonts/*.woff2` | Self-hosted IBM Plex Sans Arabic (400/600/700, Arabic + Latin subsets) and IBM Plex Mono (400/500/600, Latin) |

## The design system

Everything resolves through CSS custom properties declared in `:root`
(`ap-tokens` style block). Four axes are exposed on `<html>` and driven by
the SYSTEM panel, the command palette (`K`), and single-key shortcuts:

- `data-palette` — ink · paper · signal · mono · contrast (`P`)
- `data-density` — compact · default · editorial (`D`)
- `data-motion` — subtle · expressive · cinematic · reduced (`M`)
- `data-grid` — modular · editorial · asymmetric (`G`)

Red exists as **three roles**, not one colour — `--signal` (graphic mark,
≥3:1), `--signal-text` (small text, ≥4.5:1), `--signal-plate` (surface under
ivory text, ≥4.5:1) — and the colour lab measures the live ratios rather than
printing hard-coded ones.

Preferences persist in `localStorage` under `adspulse.system.v1`.

## Notable engineering decisions

- **RTL-first**: logical properties everywhere except pointer-driven
  coordinates (cursor, drag pucks) and time axes, which are deliberately
  physical/LTR — annotated in the CSS.
- **Arabic kinetic type splits by word, never by letter**, to preserve
  contextual glyph joining.
- **Reduced motion** is honored three ways: the OS media query seeds the
  motion axis, the axis can be forced from the panel, and every loop/reveal
  degrades to an instant state change.
- The dashboard data is generated by a **seeded PRNG** — believable and
  identical on every load.
- The responsive lab resizes a **container-queried** miniature, so the
  breakpoint logic being demonstrated is real, not simulated.
- The footer build report (nodes, FCP, transfer, frame sample) is **measured
  at runtime**, not typed in.
