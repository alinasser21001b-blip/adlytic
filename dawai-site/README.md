# Dawai site previews

## Blueprint UI (Phase 0)

Open the interactive product UI:

```bash
cd dawai-site
python3 -m http.server 8765
```

Then visit: http://127.0.0.1:8765/blueprint-ui.html

Or double-click `blueprint-ui.html` in Finder (works offline; Google Fonts need network).

Do **not** open the GitHub “file view” page — that shows source text, not the app.
