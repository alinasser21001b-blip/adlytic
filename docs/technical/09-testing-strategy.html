The two suites that carry the most weight Permission tests exercise every cell of the Blueprint's matrices, positive and negative — including the row v1 got wrong, where an assistant confirming a reservation must succeed. State-machine tests assert that no transition outside the diagram is reachable, which is the only way a state machine in a document stays true of the code.
Request window unit D09

now→20m, today→4h, soon→48h. No other value is producible.

Quantity unit unit D07

Every quantity in every payload is a pack count; no other unit can be expressed.

Honoured rate unit D11

Refusal at 4m59s does not count; at 5m01s it does. Hidden below 10 reservations. Never returns a decimal to a patient.

Line limit unit §2 Request

9 lines is refused; 8 is accepted; 0 is refused.

Watch limits unit D30

6th active watch is refused; expiry is exactly 14 days.

Arabic normalisation unit §4 F2

Alef variants, taa marbuta, tatweel, harakat and Arabic-Indic digits all fold. Case folding is a no-op and is not applied.

Server clock unit §6 Reservation

Changing the device clock does not change a countdown.

Request state-machine §6 Request

Every state reachable; every state has an exit; no transition outside the diagram.

Offer state-machine §6 Offer

Withdrawal impossible after acceptance; accepted is terminal.

Reservation state-machine §6 Reservation

expires_at is unset until held; refused always re-opens the parent; collected writes exactly one dispense record.

Subject state-machine §6 Subject lifecycle

Claim ends guardianship; memorialisation reverses within 30 days and not at 30 days plus one second.

Grant state-machine §6 Grant

invited grants nothing; expiry at 7 days; revoked preserves the row.

Verification state-machine §6 Verification

lapsed stops routing and does not cancel a live reservation.

Branch eligibility state-machine §6 Branch eligibility

Every non-receiving state exposes a reason.

Outbox state-machine §6 Session & outbox

Duplicate resolves to Accepted, never to an error.

Clinical read permission §5 clinical matrix

Every cell in the matrix is exercised, positive and negative. A pharmacist reading a dispense history fails.

Substitution permission D19

An assistant proposing a substitute is refused; a pharmacist with an unverified licence is refused.

Confirmation permission D19

An assistant confirming a reservation SUCCEEDS — this is the row v1 got wrong.

Identity leak permission §5 marketplace matrix

No branch-facing response body contains a patient name or phone, at any endpoint, in any state.

Oracle permission §5 rule 3

A request for another account's subject returns byte-identical output to a request for a non-existent one.

Branch settings permission §5 branch configuration

An assistant editing hours is refused; the last manager cannot be removed.

Audit immutability permission §5 platform matrix

No credential in the system can update or delete an audit entry.

Prescription window permission D18

A branch fetching an image after its reservation resolves is refused.

Every endpoint contract §5 · §4

Request and response schemas match this model; an undeclared field in a response fails the build.

Every event contract event table

Payload matches; a consumer receiving an undeclared field fails.

Idempotency contract D27

Replaying a write with the same key returns the original result, not a duplicate and not an error.

Clinical gate integration D18 · D42

A POM line without an image is refused at creation; a controlled item is refused outright.

Child request integration D06

Accepting a 2-of-3 offer creates a child request containing exactly the unfilled line.

Deferred notification integration D09

A branch opening in 3 hours is notified at opening, not immediately, for a 4-hour window.

Prescription revocation integration D18

Collection, expiry and cancellation each revoke access.

Deletion integration D05

Reservations are pseudonymised, audit actors tombstoned, images destroyed, dependents disposed as chosen.

Dispense write integration D22

Exactly one dispense record per collection, and no other code path writes one.
