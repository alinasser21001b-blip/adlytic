Rules that apply to every navigator

  1. Three separate builds. A patient bundle contains no pharmacy screen and no operator screen — role isolation is structural (§5).
  2. A notification always resolves to a full stack, never a bare screen with no parent (§5 nav rule 6 carried from v1).
  3. Every tab keeps its own stack and restores position on return.
  4. A modal returns to its opener and never leads into a tab.
  5. The clinical safety layer does not exist in Phase 0, so no route sits above the navigator (D16).
  6. Deep links are verified against the session before resolving; an unauthorised link lands on the guest home, never on an error.
