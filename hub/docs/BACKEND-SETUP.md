# تشغيل خادم قريب — QAREEB_AUTH_SECRET و QAREEB_PHARMACY_REGISTRY

التطبيق يشتغل بوضعين، ويقول أيّهما بصوت عالٍ في `#/admin` تحت «وضع التشغيل»:

| الوضع | معناه |
|---|---|
| `device` | ما في خادم. القواعد سارية، لكن الاعتماد يُفحص على جهاز صاحبه — وهذا ليس فحصاً |
| `server` | الجلسات موقّعة على الخادم، والإجازة تُفحص مقابل قائمة معتمدة، والسجل يُكتب حيث لا يعيد المُدقَّق كتابته |

الانتقال من الأول للثاني = **ضبط متغيّرين**. هذا الملف يشرحهما.

---

## ١ · QAREEB_AUTH_SECRET

مفتاح توقيع الجلسات ورموز التحقق. **ولّده بنفسك ولا تمرّره بأي محادثة** — مفتاح مرّ بمحادثة أو ببريد ما عاد سرّاً.

```bash
# على الماك أو لينكس
openssl rand -base64 48
```

أو:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

**الشروط:** ٣٢ محرفاً فأكثر. أقصر من هيك والخادم يرفض التشغيل ويرجّع `503` — عمداً، لأن نظام مصادقة يقبل كل شي عند سوء التهيئة أسوأ من لا شيء.

> إذا سرّبته أو شككت فيه: ولّد واحداً جديداً واستبدله. كل الجلسات القائمة تبطل فوراً، وهذا هو المطلوب.

## ٢ · QAREEB_PHARMACY_REGISTRY

قائمة من يحق له الدخول، بصيغة JSON في سطر واحد. **القائمة الفارغة تعني لا أحد يدخل** — وهذا صحيح: قائمة سماح فارغة يجب ألّا تعني «اسمح للجميع».

```json
[{"licence":"IQ-PH-1001","pharmacyId":"p1","phone":"9647801234567","pharmacistName":"د. علي حسن","expiresAt":"2027-01-01"},{"licence":"IQ-PH-1002","pharmacyId":"p2","phone":"9647801234568","pharmacistName":"د. زينب كاظم","expiresAt":"2027-06-30"}]
```

| الحقل | الشرط |
|---|---|
| `licence` | صيغة `IQ-PH-` + ٤ إلى ٨ أرقام |
| `pharmacyId` | **معرّف الصيدلية في بياناتنا** — `p1`…`p24` أو `b1`…`b10`. لازم يطابق تماماً وإلا الجلسة تُربط بفرع غير موجود |
| `phone` | موبايل الصيدلي المسؤول. يُقبل `07XX…` أو `9647XX…`. **الأرقام النموذجية `9647700000xxx` مرفوضة صراحةً** |
| `pharmacistName` | اختياري، يظهر بعد الدخول |
| `expiresAt` | اختياري. بعد هذا التاريخ الدخول يُرفض تلقائياً |

معرّفات الصيدليات الحالية: `p1` صيدلية النور · `p2` ابن سينا · `p3` الحياة · `p4` الشفاء · `p5` الرحمة · `p6` السلام · `p8` بغداد المركزية … و`b1`…`b10` للفروع خارج بغداد.

## ٣ · وين تُضبط

**app.netlify.com** ← مشروع **qareeb-iq** ← **Site configuration** ← **Environment variables** ← **Add a variable**

لكل متغيّر:
1. **Key**: الاسم كما هو أعلاه
2. **Values**: الصق القيمة
3. **Scopes**: فعّل **Functions** (هذا الأهم — بدونه الدوال ما تشوف المتغيّر)
4. **Deploy contexts**: `Production` — وإذا تريد تجرّب على المعاينة فعّل `Deploy previews` كمان

بعد الحفظ: **Deploys** ← **Trigger deploy** ← **Clear cache and deploy site**. المتغيّرات تُقرأ وقت التشغيل، لكن الدوال تحتاج نشرة جديدة أول مرة حتى تُبنى.

بالطرفية بدل الواجهة:

```bash
netlify env:set QAREEB_AUTH_SECRET "<القيمة>" --scope functions --context production
netlify env:set QAREEB_PHARMACY_REGISTRY '<JSON>' --scope functions --context production
```

## ٤ · كيف تتأكد إنه اشتغل

```bash
curl -s https://qareeb-iq.netlify.app/api/auth | python3 -m json.tool
```

**المطلوب:**
```json
{ "configured": true, "registrySize": 2, "licenceSource": "STATIC_ALLOWLIST", "regulatorVerified": false }
```

| ما تشوفه | معناه |
|---|---|
| `"configured": false` | المفتاح غير مضبوط أو أقصر من ٣٢ محرفاً |
| `"registrySize": 0` | القائمة فارغة أو JSON غير صالح — افحصها بـ `python3 -m json.tool` |
| `404` | الدوال ما انبنت — أعد النشر مع مسح الكاش |

ومن التطبيق: افتح `#/admin` ← **وضع التشغيل** لازم يكتب `server` بدل `device`.

## ٥ · المشكلة الباقية: ما في مزوّد رسائل

الرمز يُولَّد على الخادم، **لكن ما في خدمة SMS ترسله**. يعني بوضع `server` ما راح يقدر أحد يدخل فعلياً حتى تُحلّ هذي.

**للتجربة فقط**، متغيّر ثالث يرجّع الرمز بالاستجابة بدل إرساله:

```
QAREEB_DEV_ECHO_OTP = 1
```

الاستجابة تجي معها `warning` صريح، والواجهة تعرض الرمز بلون التنبيه. **يجب أن يكون مطفأً في الإنتاج** — تركه شغّالاً يعني أي أحد يعرف رقم إجازة ورقم موبايل مسجّلين يقدر يدخل.

الحل الدائم: ربط مزوّد SMS (Twilio أو مزوّد عراقي محلي) داخل `netlify/functions/auth.mjs` عند السطر الموسوم `NO_SMS_PROVIDER_CONFIGURED`. سطران، بس يحتاجان حساباً واعتمادات.

## ٦ · ما زال ناقصاً بصدق

| البند | الحالة |
|---|---|
| فحص الإجازة | مقابل **قائمتنا** المعتمدة، لا مقابل سجل وزارة الصحة مباشرة. هذا يحتاج اتفاقاً لا كوداً |
| سجل التدقيق | يُكتب على الخادم، لكن Blobs قابل للتعديل — من يملك اعتمادات النشر يقدر يعيد كتابته. `wormBacked: false` |
| تحديد المعدل | داخل الذاكرة وبكل نسخة على حدة. يوقف سكربتاً، ولا يوقف هجوماً موزّعاً |

هذي مذكورة هنا لأن إخفاءها يعني ادّعاء حماية غير موجودة.
