# قريب — ملف التسليم الكامل للواجهة
## QAREEB — COMPLETE UI HANDOFF

**لمن هذا الملف:** المصمّم أو مبرمج المواقع الذي سيستلم واجهة «قريب».
**ما هو:** كل ما تحتاجه لتفهم الواجهة الحالية، وتغيّرها، أو تعيد بناءها — الشكل، الرموز، المكوّنات، الأزرار، الدوال، العقود، القيود، وبوابة القبول.
**ما ليس هو:** رأياً في التصميم. هذا وصف لِما هو موجود ولماذا هو كذلك، لا دفاع عنه.

**قاعدة التحرير:** كل اسم برمجي (ملف، دالة، صنف CSS، رمز، مسار) مكتوب **بالإنكليزية حرفياً** كما هو في الكود. النص العربي شرح، والإنكليزي هو الشيء نفسه. لا تترجم أسماء الأصناف أو الدوال.

**تاريخ الملف:** ٣٠ تموز ٢٠٢٦ · الكوميت المرجعي `aa1cb7a` · الفرع `claude/healthcare-hub-strategy-56wyer`

> **ومعه ملف بصري:** [`UI-JOURNEYS.html`](UI-JOURNEYS.html) — افتحه في المتصفّح. يرسم الرحلات التسع بنماذج شاشات عربية/إنكليزية، ويعرض عيوب الاتجاه الثلاثة **معروضة لا موصوفة**: عمود «كان يُرسم هيك» بجانب «الصواب»، وكلاهما مقيس في Chromium. اقرأ هذا الملف للقواعد، وافتح ذاك لتراها.

# ٠ · اقرأ هذا أولاً

خمس حقائق لو لم تعرفها ستكسر شيئاً وأنت تظنّ أنك تحسّنه:

**١. البيانات كلها اصطناعية.** كل طبيب وصيدلية ومستشفى ومريض في `js/data.js` **مُختلَق**. كل رقم هاتف/واتساب عنصر نائب بصيغة `9647700000xxx`. لا يجوز إطلاق المنتج قبل استبدالها. لا تعرض أياً منها على أنه «موثّق» أو «متحقَّق منه».

**٢. الواجهة لا تقرّر شيئاً سريرياً.** كل حكم طبي — «هل هذه النتيجة غير طبيعية؟»، «هل هذا الدواء حالي؟»، «هل يحقّ لهذا الطبيب أن يرى؟» — هو نداء لدالة في طبقة النطاق. لو وجدت نفسك تكتب `if` عن معنى طبي داخل ملف واجهة، فأنت في المكان الخطأ. تفصيل في [§١٣](#١٣--واجهة-النطاق--ما-يحقّ-للواجهة-أن-تناديه) و[§١٤](#١٤--قواعد-السلامة-السريرية-التي-تحكم-العرض).

**٣. لا خطوة بناء ولا تبعيات في المتصفّح.** JavaScript عادي (classic scripts) و CSS عادي. لا React، لا Vue، لا Tailwind، لا Vite، لا npm في المتصفّح. هذا **شرط منتج** لا تفضيل: الهدف هاتف متوسط في بغداد على بيانات محمولة. إدخال إطار عمل يلغي السبب الأساسي لبنية المشروع.

**٤. ترتيب `<script>` في `index.html` حامل للبناء.** الملفات الستة عشر تتشارك نطاقاً معجمياً عالمياً واحداً. إعادة ترتيبها تكسر التطبيق بصمت. تفصيل في [§٣](#٣--الملفات-وترتيب-التحميل).

**٥. RTL ليست `direction: rtl`.** الأخطاء الحقيقية المقيسة في هذا المنتج كانت: فصيلة دم `O-` تُعرض `-O`، وجرعة دواء `20 ملغم` تُعرض `ملغم 20`، وضغط دم يُعرض بترتيبين متعاكسين على شاشتين. كلها أخطاء سلامة، وكلها من خوارزمية الاتجاه ثنائي الاتجاه (bidi). **لا تلمس أي شيء فيه رقم قبل أن تقرأ [§٨](#٨--قواعد-الاتجاه-rtl--bidi-الأخطر-في-الملف).**

# ١ · ما هو المنتج

«قريب» منتجان في تطبيق واحد، ولهما جمهوران مختلفان:

| | شبكة الرعاية · CARE NETWORK | السجل الصحي · HEALTH RECORD |
|---|---|---|
| السؤال | «وين ألقى دوا/طبيب/صيدلية مفتوحة الآن؟» | «شنو صار لي، ومنو يشوفه؟» |
| البيانات | عامة، من الشبكة | خاصة، على الجهاز |
| الملفات | `ui-discovery.js` · `ui-needs.js` · `ui-backend.js` | `ui-record.js` · `ui-network.js` |
| النطاق | `domain.js` | `emr.js` · `record.js` · `consent.js` · `network.js` |
| بدون حساب؟ | نعم كلياً | نعم — محلي أولاً |

**اللغة:** عربية عراقية عامية مقصودة (مو فصحى ومو لهجة خليجية). الإنكليزية موجودة كاملة كلغة ثانية بمفتاح `toggleLang()`.
**الاتجاه:** RTL هو الأساس. LTR حالة ثانوية.
**الوضع:** فاتح وداكن، كلاهما إلزامي وكلاهما مُختبَر.

# ٣ · الملفات وترتيب التحميل

## ٣·١ الترتيب — مُلزِم

هذا هو `index.html` كاملاً في جزئه الحرج. **الترتيب حامل للبناء:**

```html
<script defer src="js/domain.js"></script>
<script defer src="js/emr.js"></script>
<script defer src="js/record.js"></script>
<script defer src="js/consent.js"></script>
<script defer src="js/network.js"></script>
<script defer src="js/sync.js"></script>
<script defer src="js/assist.js"></script>
<script defer src="js/transport.js"></script>
<script defer src="js/data.js"></script>
<script defer src="js/ui-core.js"></script>
<script defer src="js/ui-discovery.js"></script>
<script defer src="js/ui-backend.js"></script>
<script defer src="js/ui-needs.js"></script>
<script defer src="js/app.js"></script>
<script defer src="js/ui-record.js"></script>
<script defer src="js/ui-network.js"></script>
```

**لماذا:** هذه **classic scripts** لا modules. كل `const` و`let` و`function` في المستوى الأعلى تتشارك **نطاقاً معجمياً عالمياً واحداً**. الملفات هي أقسام ملف واحد كان طوله ٥٨٩٠ سطراً، قُطع عند تعليقات أقسامه. إعادة الترتيب تُعيد «المنطقة الميتة الزمنية» (temporal dead zone) التي كان رفع الدوال في الملف الواحد يخفيها — والنتيجة شاشة بيضاء بلا خطأ واضح.

**`defer` ضرورية على كلّها.** بدونها المتصفّح يجلب ويُنفّذ الستة عشر ملفاً واحداً بعد الآخر — ستّ عشرة رحلة ذهاب وإياب متسلسلة. مقيساً على معالج مخنوق ×٤ بسرعة ~٤٠٠ كيلوبت/ث و٣٠٠ مللي ثانية تأخير (تقريب عادل لهاتف عراقي متوسط): **١٨٫٨ ثانية حتى أول شاشة مرسومة.** `defer` تحافظ على ترتيب التنفيذ بدقّة وتوازي التحميل.

# ٤ · تشغيل المشروع في خمس دقائق

```bash
git clone <repo>
cd hub

# ١) خادم ساكن — أي واحد يكفي، لا بناء
python3 -m http.server 8899
# افتح http://127.0.0.1:8899/index.html

# ٢) للاختبارات والدوال الخادمية فقط
sh tools/dev-setup.sh     # يبني كعب @netlify/blobs وروابط playwright
npm test                  # ٥٠٧ اختباراً · ١٢ حزمة
node tools/journeys.mjs   # ٦٥ رحلة في متصفّح حقيقي
node tools/audit-ui.mjs   # ١٠ كواشف بصرية
npm run build             # ملف واحد مستقل في dist/
```

**تحذير مهم:** `hub/node_modules/@netlify/blobs` هو **كعب مكتوب يدوياً في الذاكرة**، غير متتبَّع في git إطلاقاً. الحزمة الحقيقية ترمي استثناءً بلا `siteID`/`token` فتردّ الدوال `503 NO_BLOB_STORE`. لو حذفت `node_modules` تفقد ١٢ تأكيداً في `test-e2e` **بصمت**. `tools/dev-setup.sh` يعيد بناءه.

**قبل أي كوميت:** احذف روابط playwright الرمزية من `hub/node_modules`.

## ٥·٣ قاعدة الوضع الداكن — **لا نقاش فيها**

> `.dark` **يعيد تعريف الرموز، ولا يتجاوز المكوّنات.**

أي مكوّن مكتوب على `var(--ink-*)` أو `var(--dial-*)` ينقلب وحده. كتابة `.dark .something { color: … }` في كود التطبيق **ممنوعة**. هذا بالضبط مصدر أخطاء التباين التي كلّفت هذا المنتج نسخة كاملة، وإصلاحه كان بنيوياً لا تجميلياً.

**مثال على الكلفة:** زر ٩١١ كان لونه `#fff` مكتوباً يدوياً — العنصر الممتلئ الوحيد في المنتج الذي لا يستعمل رمزاً. في الوضع الداكن يصير `--alarm` هو `--alarm-lit` (#F08A80)، فيرسم أبيض على سلموني بنسبة **٢٫٤٣:١** — أعلى عنصر تحكّم خطورة في المنتج، تحت حدّ WCAG، في الوضع الذي تحصل فيه طوارئ الليل فعلاً. بعد ترميزه: ٦٫٢:١ فاتحاً و٧٫٧:١ داكناً.

## ٥·٤ كيف يُقرَّر الوضع

`js/app.js` داخل `render()`:

```js
const home = !location.hash.replace(/^#\/?/, "").split("?")[0];
const nightOS = matchMedia("(prefers-color-scheme: dark)").matches;
document.body.classList.toggle("dark", S.theme ? S.theme === "dark" : (nightOS || home));
```

اختيار المستخدم الصريح (`S.theme`) يغلب كل شيء. بدون اختيار صريح: الشاشة الرئيسية داكنة دائماً (هي «العلبة مغلقة»)، والباقي يتبع نظام التشغيل.

# ٦ · اللغة البصرية

## ٦·١ الفكرة: «المِسطرة · THE INSTRUMENT»

**سطحان فقط:**

| | العلبة · CASE | القُرص · DIAL |
|---|---|---|
| اللون | حبر عميق `--case` | ورق دافئ `--dial` |
| أين | الشاشة الرئيسية | كل شاشة أخرى |
| المعنى | الأداة مغلقة | الأداة مفتوحة |

الفصل بينهما **خيط شعري ودرجة لون**، لا صناديق داخل صناديق. الانتقال من الرئيسية إلى أي شاشة هو تغيّر إضاءة واحد مقصود يُقرأ كفتح العلبة. في الوضع الداكن لا شيء ينقلب لأن التطبيق كلّه علبة أصلاً — فهاتف في وضع ليلي الساعة ٢:٠٠ لا يرى وميضاً بين الشاشات أبداً.

## ٦·٢ المحظورات — لا نقاش فيها

| ممنوع | لماذا |
|---|---|
| **مفردة موازية لمفردة موجودة** | `.card` مقابل `.rw` · `.chip` مقابل `.c` · `.btn` مقابل `.b` — ازدواجية قائمة ولا يُضاف إليها |

# ٨ · قواعد الاتجاه RTL / BIDI — الأخطر في الملف

**اقرأ هذا القسم كاملاً قبل أن تلمس أي شيء يعرض رقماً.** كل قاعدة هنا كُتبت بعد عيب سلامة حقيقي مقيس، لا نظرياً.

## ٨·١ الخلفية التي تحتاجها

خوارزمية Unicode Bidi تعطي كل محرف صنفاً:

| الصنف | ماذا يعني | أمثلة |
|---|---|---|
| **L** | يسار-إلى-يمين | الحروف اللاتينية |
| **R / AL** | يمين-إلى-يسار | الحروف العربية |
| **EN** | رقم أوروبي | `0-9` |
| **AN** | رقم عربي-هندي | `٠-٩` (U+0660–0669) |
| **ON** | محايد آخر | `/` `-` `–` `—` `·` `←` `→` |
| **CS** | فاصل مشترك | `:` `.` `,` |

**المحايدات (ON) هي مصدر كل الأخطاء.** اتجاهها يُحلّ من جيرانها، فتنتقل.
`:` (CS) آمن لأنه يلتصق بالأرقام الأوروبية.

## ٨·٢ `embed` مقابل `isolate` — الفرق الذي كلّف

```css
.num, .n {
  font-family: var(--num); font-variant-numeric: tabular-nums;
  direction: ltr; unicode-bidi: isolate; font-weight: 400;
  white-space: nowrap;
}
```

- **`embed`** يفتح مستوى جديداً لكن يترك المحايدات المجاورة قابلة للحلّ من الخارج.
- **`isolate`** **معتم في الاتجاهين**. هذا سبب وجود البدائية أصلاً.

**العيب الحقيقي:** فصيلة دم `O-` رُسمت `-O` على بطاقة الطوارئ. `-` صنفه ON، فاتجاهه يُحلّ من جيرانه، فهاجر إلى الجهة البعيدة من الحرف. `isolate` أصلحها.

> **تصحيح مقيس — اقرأه قبل أن تبني على النظرية.** قِيست ستّة تراكيب في Chromium بـ`getBoundingClientRect()` على مستوى الكلمة (لا المحرف — الخط العربي متّصل، فصناديق المحارف متداخلة وترتيبها بالإحداثي يعطي نتيجة مشوّشة):
>
> | التركيب | النتيجة |
> |---|---|
> | `فصيلة الدم O-` — نصّ عارٍ بلا عزل | **`-O` انقلبت** |
> | `فصيلة الدم O- مسجّلة` — عارٍ وبعده عربي | **`-O` انقلبت** |
> | `unicode-bidi: embed` (بوجود عربي بعده أو بدونه) | `O-` سليمة |
> | `unicode-bidi: isolate` (بوجود عربي بعده أو بدونه) | `O-` سليمة |
>
> أي أن **الانقلاب يقع عند غياب العزل تماماً، لا عند `embed`** — في هذا التركيب وهذا المحرّك. الفرق النظري بين `embed` و`isolate` قائم ويظهر في تراكيب أخرى، لكن ما شُحن وانكسر فعلاً كان **سلسلة عارية مقحمة**، و`isolate` هو الاختيار الصحيح لأنه معتم في الاتجاهين لا لأن `embed` أنتج هذا العيب بعينه.
>
> **القاعدة العملية لا تتغيّر:** كل رقم داخل نصّ عربي يُعزَل. لكن لا تبنِ حكماً على «`embed` خطرة» — ابنِه على «**بلا عزل** خطرة».

**`white-space: nowrap` ليست تجميلاً:** `2026-07-01` كانت تُلفّ إلى `2026-07-` ثم `01`، و`148/92` إلى `148/` ثم `92`. **تاريخ مكسور تاريخ خاطئ.**

## ٨·٣ الوحدة العربية لا تدخل مجرى LTR — **أبداً**

```css
.strength { unicode-bidi: isolate; white-space: nowrap;
            font-family: var(--num); font-variant-numeric: tabular-nums; font-weight: 300; }
```

**العيب:** «٢٠ ملغم» رقم + وحدة **عربية**، وكانت ملفوفة بـ`.n` (`direction: ltr`) في **أحد عشر موضعاً**. داخل ذلك المجرى الوحدة صنفها AL، والمسافة الرابطة تُحلّ إلى R لأن الأرقام تتصرّف كـR، وعكس المنطقة من المستوى ١ يضع **الوحدة قبل الرقم**: كل صفّ في قائمة الأدوية كان يُقرأ «ريفاروكسابان ملغم 20» — على الشاشة نفسها التي يحذّر متنها «التركيز مهم — 2.5 ملغم غير 50 ملغم».

**القاعدة العملية في `js/ui-core.js`:**

```js
const UNIT_TIGHT = /^(%|°C|°F|°)$/;
const HAS_ARABIC = /[؀-ۿ]/;

function measure(v, unit) {
  const u = String(unit || "").trim();
  const num = `<span class="num">${esc(String(v))}</span>`;
  if (!u) return `<span class="nw">${num}</span>`;
  // وحدة عربية: الرقم وحده داخل المجرى، والوحدة خارجه
  if (HAS_ARABIC.test(u)) return `<span class="nw">${num} ${esc(u)}</span>`;
  // وحدة لاتينية: الاثنان معاً داخل المجرى
  return `<span class="num nw">${esc(String(v))}${UNIT_TIGHT.test(u) ? "" : " "}${esc(u)}</span>`;
}
```

## ٨·٤ التسلسل الزمني لا يُعبَّر عنه بسهم — **ممنوع منعاً باتاً**

ليست مسألة وضوح، بل **انعكاس فعلي**. `U+2190 ←` صنفه `Bidi_Class=ON` و`Bidi_Mirrored=No`، فيُعاد ترتيبه ولا يُقلَب.

**العيب المقيس:** بين رقمين، تتجمّع المجموعة كلها في مقطع LTR واحد داخل سطر عربي، فيصل `7.1 ← 8.4` إلى العين **`8.4 → 7.1`**. الصناديق مقيسة: `7.1` عند x321‑337، السهم 337‑354، `8.4` عند 354‑370.

> **مريضة سكري ارتفع خضابها من ٧٫١ إلى ٨٫٤ قرأت أنها تحسّنت. وقرأ طبيبها الشيء نفسه.**

**البديل الملزم:**
- كل نقطة **على سطرها بتاريخها**
- **الأقدم أعلى** — فالقراءة نزولاً = تقدّم في الزمن
- الحركة تُحمل بـ**كلمة**: ارتفع / انخفض / ما تغيّر
- مع **المدى المرجعي**
- وأي فاصل محايد بين رقمين يقع في الفخ نفسه: `4–5.6` ممنوعة، والصواب «من ٤ إلى ٥٫٦»

**يحرس هذا اختباران في `tools/test.mjs`** يرفضان أي سهم داخل `join()` أو ملاصقاً لـ`${}`، **وكاشف `rtl` في `tools/audit-ui.mjs`.**

## ٨·٥ ضغط الدم — زوج لا رقمان

```js
function bpPair(sys, dia, unit) {
  const u = String(unit || "").trim();
  return `<span class="num nw">${esc(String(sys))}/${dia == null ? "—" : esc(String(dia))}${u ? " " + esc(u) : ""}</span>`;
}
```

`/` محايد. لو رُسم الانقباضي والانبساطي كـ`.num` منفصلين حوله، انقلب الترتيب. **كان يُعرض بترتيبين متعاكسين على شاشتين مختلفتين في هذا المنتج.** الزوج كلّه مجرى واحد.

# ١٠ · نموذج التنقّل والمسارات

## ١٠·١ الشريط السفلي — أربع تبويبات

المصدر: `js/ui-core.js` — `nav(active)`

```js
const items = [
  ["#/",         "clock",  "booklet"],    // الدفتر
  ["#/record",   "seal",   "sheets"],     // أوراقي
  ["#/care",     "stetho", "available"],  // المتوفّر
  ["#/settings", "user",   "settings"],   // حسابي
];
```

**الترتيب في RTL يُقرأ من اليمين:** الدفتر ← أوراقي ← المتوفّر ← حسابي.

**أسماء بديلة تُحوَّل تلقائياً:**
```js
const NAV_ALIAS = { explorer:"available", pharmacies:"available", doctors:"available",
                    care:"available", home:"booklet", record:"sheets" };
```
كل موضع نداء قديم يبقى يشتغل: **الباب انتقل، لا الغرفة.**

**قاعدتان تخصّان الشريط:**

1. **`nav()` هي التي تحجز ارتفاعها** عبر `<div class="nav-space" aria-hidden="true">`. الشريط `position:fixed` فيطفو فوق نهاية ما خلفه. مقيساً قبل وجود الحجز: آخر صفّ في فهرس السجل عند y=792 وحافة الشريط عند y=778 — غير مقروء وغير قابل للّمس. **موضع النداء ينسى، الدالة لا تنسى.**
2. **`role="tablist"` + `role="tab"` + `aria-selected` إلزامية** — من مسار امتثال Apple. `nav-space` مضاف `aria-hidden` لأنه مسافة لا محتوى، ولهذا **يجب أن يعيش إلى جانب أدوار التبويب لا بدلاً منها**: أحدهما يصلح ما يسمعه قارئ الشاشة، والآخر يصلح ما يصله الإبهام.

## ١٠·٢ الترويسة

```js
header({ back: true, title: "…", right: "…" })  // شاشة داخلية
header()                                         // الرئيسية: علامة + موقع + لغة + وضع
```

## ١٠·٣ الموجّه

`js/app.js` — `route()`. موجّه هاش، بلا مكتبة:

```js
function route() {
  const h = location.hash.replace(/^#/, "") || "/";
  const [path, qs] = h.split("?");
  const params = new URLSearchParams(qs || "");
  const p = path.split("/").filter(Boolean);
  if (!p.length) return screenHome();
  switch (p[0]) {
    case "needs":       return screenNeeds();
    case "doctors":     return screenDoctors(params);
    case "doctor":      return screenDoctor(p[1]);
    case "pharmacies":  return screenPharmacies();
    case "pharmacy":    return screenPharmacy(p[1]);
    case "hospitals":   return screenHospitals();
    case "hospital":    return screenHospital(p[1]);
    case "care":        return p[1] ? screenCare(p[1]) : screenAvailable();
    case "product":     return screenProduct(p[1]);
    case "start":       return screenStart();
    case "explorer":    return screenExplorer();
    case "rx":          return p[1] ? screenVariant(p[1]) : screenRxSearch();
    case "need":        return p[1] === "new" ? screenNeedNew(qs) : screenNeed(p[1]);
    case "radar":       return screenRadar(p[1]);
    case "wait":        return screenRadarWait(p[1]);
    case "med":         return screenMed(p[1]);
    case "partner":     return p[1] === "doctor" ? screenPartnerDoctor(p[2]) : screenPartner(p[1]);
    case "search":      return screenSearch();
    case "me":          return screenMe();
    case "trust":       return screenTrust();
    case "admin":       return screenAdmin();
    case "settings":    return p[1] ? screenSettingsSub(p[1]) : screenSettings();
    case "privacy":     return screenPrivacy();
    case "about":       return screenAbout();
    case "record":      return p[1] ? screenRecordSection(p[1], p[2]) : screenRecord();
    case "clinical":    return p[1] === "inbox" ? screenClinicalInbox() : screenClinical(p[1]);
    case "redeem":      return screenRedeem(p[1]);
    case "lab":         return screenLab(p[1], p[2]);
    case "imaging":     return p[1] === "study" ? screenImagingStudy(p[2]) : screenImaging(p[1], p[2]);
    case "pharmacy-rx": return screenPharmacyRx(p[1], p[2]);
    default:            return screen404();
  }
}
```

| **«تروح حتى لو ما اخترتها»** | `SAFETY_FLOOR` = `[allergies]` | `CONSENT.SAFETY_FLOOR` |
| **«تنفتح بالطوارئ بلا ما تسألك»** | `EMERGENCY_SCOPES − SAFETY_FLOOR` = `[medications, conditions, summary]` | `CONSENT.EMERGENCY_SCOPES` |
| **«ما تروح إلا إذا سلّمتها بيدك»** | `ALL_SCOPES − ما سبق` (٧ نطاقات، مطوية) | `CONSENT.ALL_SCOPES` |
| **الحساس** | `SENSITIVE_CLASSES` — لا يدخل منحة عادية أبداً | `CONSENT.SENSITIVE_CLASSES` |
| **الفجوات** | أسئلة بلا جواب — ليست نطاقات أصلاً | `ASSIST.gapStatements()` |

**لا يوجد شريط محايد.** المسوّدة الأولى كان فيها واحد اسمه «أوراقك» — وسلّة مسمّاة بلا شيء هي حيث تختبئ أسماء التخزين. «الأدوية الحالية / التحاليل / المشاكل النشطة» تحت عنوان محايد = **فهرس محتويات بخطّ أفضل**، وهذا بالضبط ما حلّت هذه الشاشة محلّه.

**كل صفّ ورقة (`sheetRow`) يحمل ثلاثة أشياء:**
1. العدد (بصيغة الجمع العربية الصحيحة عبر `countAr`)
2. ما تفعله الورقة
3. **سجلّ الحيازة**: «ما راحت من قبل» / «عند د. سهى الآن — باقي ٣ أيام» / «آخر مرة راحت الثلاثاء مع د. أحمد»

الثالث هو ما يحوّل الصفّ من سطر جرد إلى **سجلّ حيازة** — وهو الفرق بين فهرس محتويات وهذه الشاشة.

> **معلومة جديدة لم يعرضها أي شاشة في هذا المنتج من قبل:** هناك أربعة نطاقات يقدر المسعف أن يفتحها **بلا ما يسألك**، الطبقة الأولى من كسر الزجاج، ستّون دقيقة. كانت موجودة في `EMERGENCY_SCOPES` وغير معروضة.

# ١٤ · قواعد السلامة السريرية التي تحكم العرض

**هذه ليست تفضيلات تصميم. النطاق يفرضها، والواجهة يجب ألا تنقضها.**

| # | القاعدة | لماذا |
|---|---|---|
| ١ | **الحساسية أولاً، دائماً** | قبل أي شيء آخر على أي شاشة تعرض مريضاً |
| ٢ | **نتيجة غير طبيعية لم يُقرّها أحد تُميَّز عن نتيجة مُقرَّة** | الفرق بينهما هو حلقة الفشل التي تقتل |
| ٣ | **دواء `UNCONFIRMED` لا يُعرض أبداً كأنه مؤكَّد حالي** | دواء انتهت مدّته أو ما أكّده أحد ٦ أشهر ليس دواءً حالياً — ولا موقوفاً أيضاً |
| ٤ | **نتائج من مختبرين (`mixedLabs`) أو بوحدتين (`mixedUnits`) لا تُرسم كخطّ واحد واثق** | |
| ٥ | **ما استخرجته آلة لا يُعرض كحقيقة** | يبقى موسوماً «بانتظار تأكيد طبيب» — ولا مسار كود يجعله حقيقة بلا إنسان مرخّص |
| ٦ | **الغياب يُصرَّح به** | «ما مسجّل أي حساسية» ≠ فراغ. الفراغ وعدم التسجيل يبدوان متطابقين ويعنيان **عكسين** |
| ٧ | **حالة المزامنة صادقة** | لا علامة صحّ قبل تأكيد الخادم — لكنها **تتوقف عن احتلال الشاشة** |
| ٨ | **منشأة غير موثّقة تظهر كذلك** | بلا إيحاء بالفشل، وبلا إيحاء بالتوثيق |
| ٩ | **«غير معروف» لا يلبس لون «غير طبيعي»** | نتيجة بلا مدى مرجعي لم تفشل في فحص — لم يُعطَ لها فحص تفشل فيه. **قُلها بالكلمات.** |
| ١٠ | **كل ما يكتبه المريض يُختم `SOURCE.PATIENT` + `PATIENT_REPORTED`** | والختم يظهر **على شاشة الطبيب أيضاً**. `preVisitBrief` إسقاط يعيد تسمية الحقول عمداً، فدواء كتبه المريض قبل خمس دقائق ظهر مرّة في قائمة الطبيب **مطابقاً تماماً للموصوف**. |
| ١١ | **إذا لم يوجد مدى مرجعي، لا تصنّف النتيجة «طبيعية»** | |
| ١٢ | **بطاقة الطوارئ تقول ما هو غير مسجَّل** | فصيلة دم فارغة وأخرى غير مسجّلة تبدوان متطابقتين على الشاشة وتعنيان **عكسين** في ردهة الحوادث |

**ثلاث حالات صادقة يتجنّبها معظم الأنظمة — ويجب أن تُعرض:**

| الحالة | لماذا موجودة |
|---|---|
| `MED_STATE.UNCONFIRMED` | عرضه كـ«حالي» كذب مريح |
| `EXTRACT_STATE.EXTRACTED` | ما قرأته الآلة **ادعاء** لا حقيقة |
| `immunization.documented = false` | «أتذكّر إني أخذته» ≠ «مكتوب ببطاقة». دمجهما **يُضيّع طفلاً**. |

**ولا تختلق أبداً:** أطباء · صيدليات · مستشفيات · توثيق · نتائج سريرية · تفسيرات مختبرية · توفّر أدوية · مواعيد · تاريخ مريض.

## ١٦·١ الضمان الشامل — §٣١ في `css/qareeb.css`

كان في الملف **ستّة** كتل `prefers-reduced-motion` منفصلة، كل واحدة تُسمّي المحدّدات التي تعرفها. هذا يشتغل بالضبط حتى يضيف أحدهم حركةً وينسى — وكانت **سبع وثلاثون** حركة وانتقالاً قد تراكمت مقابل ستّ قوائم مكتوبة يدوياً. اضطرابات التوازن والشقيقة ليست حالات هامشية، و«ذكرنا معظمها» ليس إعداداً يقدر إنسان أن يعتمد عليه.

فالضمان يُعطى **مرّة واحدة، لكل شيء، في نهاية التتالي**:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    animation-delay: 0s !important;
    transition-duration: .01ms !important;
    transition-delay: 0s !important;
    scroll-behavior: auto !important;
  }
}
```

> ⚠️ **المدّة تنهار إلى `.01ms` ولا تُضبط على `none` — وهذا فرق حرج.** حركة دخول تبدأ من `opacity: 0` وأُطفئت بـ`animation: none` تترك عنصرها **غير مرئي للأبد**. `.01ms` تُشغّلها فوراً حتى حالتها **النهائية**.

الكتل الستّ الأصلية **باقية**، لأن عدّة منها تصحّح أيضاً تحوّلاً أو شفافيةً ساكنةً كانت الحركة ستوفّرها.

**كاشف `motion` في `tools/audit-ui.mjs` يشغّل الصفحة بـ`prefers-reduced-motion: reduce` ويرصد أي عنصر ما زال يتحرّك. يجب أن يبقى صفراً.**

## ١٨·٢ الرؤوس — `netlify.toml`

```toml
X-Content-Type-Options  = "nosniff"
Referrer-Policy         = "strict-origin-when-cross-origin"
X-Frame-Options         = "SAMEORIGIN"
Permissions-Policy      = "geolocation=(self), microphone=(), camera=(), payment=()"
Content-Security-Policy = "default-src 'self'; font-src 'self' https://fonts.gstatic.com; \

  connect-src 'self'; img-src 'self' data:; frame-ancestors 'none'"
```

> ⚠️ **`geolocation=(self)` حرجة.** `netlify.toml` في جذر المستودع (وهو لمشروع آخر) يرسل `geolocation=()` وهذا **يقتل `getCurrentPosition` بصمت**. كل فرضية «قريب مني» تعتمد على هذا الرأس. **لا تلمسه.**

**الكاش:** CSS و JS و HTML بلا بصمة، فيجب أن تُعاد المصادقة عليها (`must-revalidate`) وإلا شُحن تعديل إلى كاش قديم. **`sw.js` هو الوحيد بـ`no-store`** — لأنه يقرّر ما يراه الجميع، فلو كان هو قديماً فالنشر غير مرئي مهما كان باقي الملف صحيحاً.

# ١٩ · البناء والنشر

## ١٩·١ البناء

`build-single.mjs` يُخرج **متغيّرين**، لا واحداً:

```bash
node build-single.mjs                # → dist/qareeb.html
                                     #   بلا أي مرجع خارجي إطلاقاً — لمستضيفات CSP الصارمة
node build-single.mjs --with-fonts   # → dist/qareeb.web.html
                                     #   يُبقي وسم الخط — للاستضافة العادية حيث يُحمَّل الخط العربي الحقيقي
```

`npm run build` ينفّذ الأول فقط.

**الأحجام المقيسة:**

| الملف | ما يبلّغه السكربت | الحجم الفعلي على القرص |
|---|---:|---:|
| `dist/qareeb.html` | ١٠٥٢ KB | **١١٠١ KiB** (١٬١٢٧٬٤٨٨ بايت) |

> **الرقمان ليسا متناقضين ولا خطأ:** السكربت يعدّ **المحارف** (وحدات UTF‑16)، والقرص يعدّ **البايتات** بترميز UTF‑8 حيث كل حرف عربي بايتان. الفرق كلّه عربي. **الحجم الذي يهمّ للنقل هو ١١٠١ KiB**، وهو ما يجب أن تقيس عليه.

> **`dist/qareeb.web.html` ليس أثراً فاسداً** — هو متغيّر `--with-fonts` المشروع. لكنه **قديم**: بُني في ٢٩ تموز، أي **قبل** دمج إعادة التصميم، ولم يُعَد بناؤه. لو احتجته، أعِد بناءه. وفي كلّ الأحوال **ليس** هو حمولة نشر Netlify — النشر من `hub/` مباشرةً (`publish = "."`).

## ١٩·٢ النشر

| | |
|---|---|
| المزوّد | Netlify |
| المشروع | **`qareeb-iq`** — ولا غيره. **لا تنشئ ولا تنسخ ولا تفرّع مشروعاً آخر.** |
| مجلّد البناء | **`hub/`** — لا جذر المستودع |
| `publish` | `.` |

## ١٩·٣ ⚠️ فرع الإنتاج ليس `main` — اقرأ هذا قبل أن تدفع أي شيء

**مقيس من سجلّ نشر Netlify في ٣٠ تموز ٢٠٢٦، لا مفترَض:**

```
deploy 6a6bd176e1742bf8600017d8      published 22:34:47Z · state ready
  context:    production
  alias:      https://qareeb-iq.netlify.app
  branch:     claude/healthcare-hub-strategy-56wyer     ← لا main
  commit_ref: 1c336f7
```

ثلاثة نشرات إنتاج متتالية (21:25 · 22:22 · 22:34) كلها من هذا الفرع.

**أي أن `qareeb-iq.netlify.app` يُبنى من فرع عمل، لا من `main`.** ولهذا عطبان، وأيّهما يقع يعتمد على مكان عملك:

| إن دفعتَ إلى | ماذا يحصل |
|---|---|
| **`claude/healthcare-hub-strategy-56wyer`** | ينزل إلى الإنتاج **مباشرة، بلا مراجعة ولا بوّابة** |
| **`main` عبر PR** | الإنتاج **يتجمّد بصمت** — لا خطأ، لا إشعار، فقط لا جديد |

**ولا تحذف ذلك الفرع.** حذفه يترك الموقع مثبّتاً على آخر نشر بلا نشر بعده — عطل صامت.

**الإصلاح** (يحتاج صلاحية على لوحة Netlify، ولا يمكن من المستودع):

```
app.netlify.com → qareeb-iq → Site configuration
  → Build & deploy → Continuous deployment
  → Branches and deploy contexts → Production branch
  →  claude/healthcare-hub-strategy-56wyer  ⟶  main   → Save
```

**افعله وأنت تعلم أن `main` والفرع متطابقان**، وإلا صار التحويل تغييراً بصرياً مفاجئاً على الموقع الحيّ. كانا متطابقين عند كتابة هذا (`tree 07a4e9d1`)؛ تحقّق قبل التحويل بـ:

```bash
git rev-parse origin/main^{tree} origin/<الفرع>^{tree} | uniq | wc -l   # 1 = متطابقان
```

**كيف تتأكّد أن التحويل نجح:** أعد قراءة آخر نشر — يجب أن يصير `branch: main` و`commit_ref` مساوياً لرأس `main`، مع بقاء بصمة **٦ قواعد إعادة توجيه**.

## ٢٠·٢ درسان يستحقّان التحذير

**١. اختبار أخضر لا يعني أن الشيفرة تُحلَّل نحوياً.** علامة اقتباس مائلة (backtick) واحدة داخل **تعليق HTML** داخل قالب نصّي أسقطت التطبيق كلّه — و٤٦٢ تأكيداً بقيت خضراء لأن أياً منها لا يحلّل ما يُشحن. حدث هذا **أربع مرّات**. يوجد الآن اختبار حارس في `tools/test.mjs` اسمه:
> `"no HTML comment inside a template literal contains a backtick"`

**٢. اختبار الرحلة يشفّر خصائص سلامة حقيقية.** حين كُسر تأكيدان في `journeys.mjs`، تبيّن أنهما يشفّران قاعدتين حقيقيتين (كل نقطة مؤرّخة، والأقدم أولاً). **أُصلحت الواجهة، لا الاختبار.** لو انكسر تأكيد رحلة عندك، **أبلغ عنه ولا تعدّله**.
