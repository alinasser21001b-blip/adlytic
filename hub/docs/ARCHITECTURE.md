# PHASE 3 — نموذج النطاق

## ٣·١ الهوية

```
Patient
  id                 معرّف قريب الداخلي — المفتاح، ولا شيء غيره
  nameParts          { given, father, grandfather, family }   ← اسم الأب حقل
  birthDate          + birthDateEstimated: bool
  sex
  identifiers[]      { type, value, verification, validFrom, validTo }
                     ← لا قيد تفرّد على أيٍّ منها
```

**قرار المفتاح.** التغطية عالية (٤٠+ مليون بطاقة مقابل ~٤٦ مليون نسمة) — لكن **ثبات الرقم عبر إعادة الإصدار غير معروف**، ومليون عراقي بلا وثائق، والهويات القديمة ما زالت متداولة بصلاحية غير محسومة. مفتاح قد يتغيّر بصمت يشطر مريضاً أو يدمج اثنين بلا خطأ يظهر.

**مستوى التحقق لكل معرّف:** `self_declared` → `visually_sighted` → `machine_read`. الأخير متاح **اليوم** بكاميرا هاتف: البطاقة تحمل MRZ بمعيار ICAO وشريحة NFC.

**حقول مرفوضة، مفروضة لا موثّقة:** الديانة، المذهب، القومية، صورة البطاقة، البصمة الحيوية.

## ٣·٢ الفصل الحاكم: الزيارة ≠ السجل الطولي (§٧)

| | الزيارة · Encounter | القائمة الطولية · Longitudinal |
|---|---|---|
| السؤال | ماذا حدث في هذا اللقاء؟ | ما الصحيح عن هذا المريض الآن؟ |
| القابلية للتعديل | **غير قابلة** بعد التوقيع | قابلة، بتاريخ تغيير كامل |
| التصحيح | ملحق باسم صاحبه وسببه | تحديث موسوم بمن ولماذا |
| العلاقة | يُشير للقوائم كما كانت | مستقلة عن أي مستند |

هذه القاعدة هي الفرق بين سجل طولي وكومة PDF، وهي أغلى ندم أسترالي في هذا المجال.

## ٣·٣ الكيانات وعلاقاتها

```
Patient ──┬── Encounter ──── Addendum
          ├── Condition ──── (episodeId, encounterId)
          ├── Medication ─── Prescription ─── Dispense
          ├── Allergy
          ├── Procedure
          ├── Observation/Result ─── Order
          ├── Document ────── Claim  (extracted → confirmed/rejected)
          ├── Immunization
          ├── Episode ─────── يجمع كل ما سبق في قصة
          ├── Task ────────── مشتقة من الغياب
          ├── Appointment ─── يصير Encounter عند الحضور فقط
          ├── Share ───────── نطاقات + مدة + طريقة موافقة
          └── AccessEntry ─── كل قراءة، ناجحة أو مرفوضة
```

## ٣·٤ ثلاث حالات صادقة يتجنّبها معظم الأنظمة

| الحالة | لماذا موجودة |
|---|---|
| `MED_STATE.UNCONFIRMED` | دواء انتهت مدّته أو ما أكّده أحد ٦ أشهر ليس دواءً حالياً — لكنه ليس موقوفاً أيضاً. عرضه كـ«حالي» كذب مريح |
| `EXTRACT_STATE.EXTRACTED` | ما قرأته الآلة **ادعاء** لا حقيقة، ولا مسار كود يجعله حقيقة بلا إنسان مرخّص |
| `immunization.documented=false` | «أتذكّر إني أخذته» ≠ «مكتوب ببطاقة». دمجهما يُضيّع طفلاً |

# PHASE 4 — الأدوار والصلاحيات والموافقة

## ٤·١ نموذج الموافقة: **opt-in**، وهذا قرار قانوني لا تفضيل

ملفّي الإماراتية تعمل بنموذج الانسحاب (opt-out) — وتنجح، **لأن منظِّماً ألزم كل منشأة مرخّصة بالمشاركة**. قريب بلا تفويض وبلا نص: **لا قانون حماية بيانات نافذ في العراق، ولا سلطة حماية بيانات، ولا أساس تشريعي للموافقة على مشاركة السجل**.

في هذا الفراغ، **الموافقة الموثّقة ليست بنداً امتثالياً — هي الأساس القانوني الوحيد الذي يملكه المنتج.**

## ٤·٢ قواعد المشاركة

| القاعدة | التنفيذ |
|---|---|
| المريض وحده يمنح | `grantedBy !== patientId` → `PATIENT_MUST_GRANT` |
| لا مشاركة بلا نهاية | لا مسار كود ينشئ منحة غير محدودة؛ السقف ٩٠ يوماً، ولا يوجد «للأبد» |
| الانتهاء **مشتق** | يُحسب من الساعة كل قراءة — مشاركة انتهت ٣ فجراً ليست مفتوحة ٩ صباحاً |
| الإلغاء فوري وبلا سبب | من يُطالَب بتبرير سحب موافقته لم يملكها أصلاً |
| **أرضية السلامة** | الحساسية تُشارك مع أي منحة — طبيب يرى الملف بلا الحساسية أخطر من طبيب لا يرى شيئاً |
| الحساس بموافقة ثانية | لا يدخل منحة افتراضية أبداً |
| التضييق نعم، التوسيع لا | الموافقة تمنح **على الأكثر** ما طُلب |
| الطلب يموت وحده | ١٥ دقيقة — نافذة تعيش للأبد تُضغط سهواً بعد ستة أسابيع |
| كل قراءة مسجّلة | **بما فيها المرفوضة** — سجل النجاحات وحده لا يجيب «هل حاول أحد؟» |

## ٤·٣ بوابتان مختلفتان — وخلطهما خطأ سلامة

| | `canReadShared` | `canWriteClinical` |
|---|---|---|
| الشرط | موثّق **أو** مُدّعٍ ببعض الأدلة | موثّق بالكامل: رقم إجازة + نقابة + اختصاص |
| المنطق | رفض القراءة يدفع الاستشارة لصورة واتساب — أسوأ للمريض | الكتابة تصير حقيقة يعتمد عليها واصف آخر |

## ٤·٤ كسر الزجاج

يُفحص **قبل** المشاركة لا بعدها، لأن سبب وجوده أنه لا مشاركة. ساعة واحدة · يُبلَّغ المريض · يبقى باسم فاعله للأبد · الشاشة تقول ثمنه قبل الضغط.

# ما لم يُبنَ — بصراحة

| البند | لماذا |
|---|---|
| **فصل `app.js` إلى وحدات (§٢٩)** | ٥٨٧٥ سطراً تشتغل ومغطّاة باختبارات. الطلب نفسه يقول «لا تهدم الموجود بدون سبب». الوحدات الجديدة منفصلة نظيفاً؛ تفكيك القائم عملية مستقلة بمخاطر ارتداد حقيقية |
| **العملية الجراحية المفصّلة (§٢١)** | العملية تُسجَّل وتدخل الحلقة والخط الزمني، لكن بنية ما قبل/أثناء/بعد الجراحة لم تُبنَ |
| **حفظ السجل على الخادم** | محلي أولاً — والكهرباء لا الإنترنت هي نمط العطل في العراق. المزامنة عمل طبقة البيانات ولم تُوصَّل بعد |
| **الأشعة/DICOM (§١٠)** | مؤجَّل بوعي |
| **الذكاء الاصطناعي (§٢٨)** | مؤجَّل بوعي — لكن **بوابته بُنيت**: خط الاستخراج جاهز، ولا مسار يجعل ادعاء آلة حقيقة سريرية بلا إنسان مرخّص |
| **مجمّع المعرّفات المحجوزة (DHIS2) ومزامنة نطاق العيادة (Bahmni)** | قرارات من عدسة العراق تخصّ التخزين، لا القواعد |
